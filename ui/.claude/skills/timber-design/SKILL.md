# Timber design

Read [DESIGN.md](../../../node_modules/@oaknorthbank/components/DESIGN.md) in full before writing or changing UI, and
follow it. It is the design contract for Timber: the rules, every colour token
with its light and dark value, the type scale, and the spacing and radius
scales.

- For a component's exact props, variants or import path, load
  `timber-components`.
- For any user-facing text, load `timber-copy`.

The task is done when every item in the checklist under "Do's and Don'ts" in
DESIGN.md passes, including rendering the UI in both light and dark themes.
